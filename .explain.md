# Explain context — twd-vue-example

Repo-specific context for the `explain` agent.

## How this file grows

The agent never edits this file. It reports what it could not work out, and a human decides
what becomes context. Two inputs:

1. The **Couldn't determine** section of an explain comment.
2. A reviewer replying to the comment with what was missing or wrong.

Turn either into a line in the right block below. If the *method* was at fault rather than the
context, the fix belongs in `.claude/skills/explain/SKILL.md` instead.

Each block feeds exactly one section of the comment: Mental model, Noise, Risk, Vocabulary feed
Mental model, What stayed the same, Where to look, and In one minute respectively. A fact that
feeds no section does not belong here. Delete lines that stop being true; a stale one costs more
than a missing one.

## Mental model

Vue 3 SPA (Composition API) → `src/api/` (axios) → json-server on `:3001`.
Routing is vue-router; there are no route guards and no global store.
TWD tests run in a real browser beside the running app; vitest tests run in jsdom.

## Noise

Usually mechanical. Say so and move on.

- `data/data.json` and `src/twd-tests/mocks/*` — fixtures and seed data. A change here is
  data, not behaviour, unless a contract changed with it.
- `package-lock.json` — never explain it.
- Whitespace-only or import-order churn in `.vue` files.

## Risk

A small diff here is not a small change.

- `contracts/todos-3.0.json` — contract validation runs in `error` mode with `strict: true`
  (see `twd.config.json`), so a change here invalidates every mock that omits a new field,
  across all test files.
- `src/twd-tests/support/componentHost.ts` — every component test mounts through it.
- `src/api/todos.ts` — the only network boundary; mocks match on path, not on the axios
  `baseURL`.

## Vocabulary

- **flow test** — drives the whole app through `twd.visit()`. **component test** — renders one
  component with Testing Library. Both live in `src/twd-tests/` and run in the browser.
- `screenDom` is scoped to the app root; `screen` queries the whole document.
- **TWD** is the browser test runner (`twd-js`), not a framework the app is built on.
